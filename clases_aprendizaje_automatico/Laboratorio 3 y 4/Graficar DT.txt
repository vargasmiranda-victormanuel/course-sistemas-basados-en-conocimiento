import matplotlib.pyplot as plt
from sklearn.datasets import fetch_california_housing, load_breast_cancer
from sklearn.tree import DecisionTreeRegressor, DecisionTreeClassifier, plot_tree

# ==========================================
# 1. VISUALIZAR DECISION TREE REGRESSOR
# ==========================================
print("Entrenando y graficando DecisionTreeRegressor...")

# Cargamos un subconjunto de datos para el ejemplo
california = fetch_california_housing()
X_reg, y_reg = california.data, california.target

# Instanciamos con una profundidad máxima de 3 para que el gráfico sea legible
reg_tree = DecisionTreeRegressor(max_depth=3, random_state=42)
reg_tree.fit(X_reg, y_reg)

plt.figure(figsize=(20, 10))
plot_tree(
    reg_tree, 
    feature_names=california.feature_names,
    filled=True, 
    rounded=True, 
    fontsize=10
)
plt.title("Árbol de Decisión para Regresión (Precios de Casas en California)")
plt.show()

# ==========================================
# 2. VISUALIZAR DECISION TREE CLASSIFIER
# ==========================================
print("\nEntrenando y graficando DecisionTreeClassifier...")

cancer = load_breast_cancer()
X_clf, y_clf = cancer.data, cancer.target

# Instanciamos con profundidad 3
clf_tree = DecisionTreeClassifier(max_depth=3, random_state=42)
clf_tree.fit(X_clf, y_clf)

plt.figure(figsize=(20, 10))
plot_tree(
    clf_tree, 
    feature_names=cancer.feature_names,
    class_names=cancer.target_names, # Muestra 'malignant' o 'benign' en las hojas
    filled=True, 
    rounded=True, 
    fontsize=10
)
plt.title("Árbol de Decisión para Clasificación (Detección de Cáncer de Mama)")
plt.show()


¿Cómo leer estas gráficas?

Cuando ejecutes el código, se abrirán dos ventanas con los diagramas de flujo. Cada cuadro (nodo) contiene información clave. Si miras cualquier nodo, lo leerás de la siguiente manera:

La Condición (ej. MedInc <= 5.04): Es la regla matemática que el modelo creó. Si la respuesta es Verdadera, el dato viaja por la flecha izquierda. Si es Falsa, viaja por la flecha derecha. (Las "hojas" o nodos finales no tienen condición porque ahí termina el viaje).

gini o squared_error: Es el nivel de error o impureza que existe en ese punto exacto del árbol. El objetivo del algoritmo es que este número vaya bajando a medida que bajas por las ramas.

samples: Cuántas filas de tu dataset original cumplieron las reglas para llegar hasta ese cuadro en particular.

value: * En Regresión: Es el valor promedio predicho para los datos que caen en ese nodo.

En Clasificación: Es un arreglo (ej. [50, 10]) que te dice cuántas muestras de ese nodo pertenecen a la Clase 0 y cuántas a la Clase 1. El color de la caja suele oscurecerse hacia el color de la clase mayoritaria.
